# LookSAM L3-TC wiring plan (decoder → vit → mamba)

## Goal / HARD RULE
DONE only when fresh `FORCE_CUDA=1 ./build.sh` → `wiring_check.py` shows
`path=L3-TC-megakernel(wgmma)` for the cell AND `test_l3tc_tail_gate` A/A/A
bit-identical passes. Else stay eager, loud+cited. No false-done.

## Eager LookSAM semantics (the parity target)
- train loop: fwd+bwd at p → g (reduced grad). Then:
  - `should_sam_step()` == (`_global_step % k == 0`); `_global_step` starts 0,
    increments inside `step()`. So SAM FIRES at step 1 (0%5==0), and every k.
  - `sam_step`: GLOBAL grad norm `‖g‖` over ALL tensors (compute_sam_grad_norm_
    device_side); `rho_over_norm = rho/‖g‖`; perturb `p' = p + rho_over_norm·g`
    (backup = p.clone()); 2nd fwd+bwd at p' → g_sam; restore p; `sam_dir = g_sam - g`
    (PERSISTED state). p.grad restored to g.
  - `step()` (EVERY step): `g_adj = (1-alpha)·g + alpha·sam_dir`; AdamW on g_adj.
- Intervening steps: reuse cached sam_dir (no 2nd backward).

## In-kernel design (decoder TC kernel; same shape vit/mamba)
Insert between B2 (reduced grad g ready) and P3, guarded `if constexpr (Opt==LookSAM)`:
- sam_dir lives in the persistent `extra` state slice (state[2*total:3*total]) ==
  st.sam_dir buffer, total floats, persists across steps. Standard 3*total+1 state.
- NEW transient workspace (carved LAST, unconditional, like muon scratch):
  - `sam_backup` [total]   — param backup for exact restore
  - `sam_grad`   [total]   — g_sam (2nd-backward reduced grad), must NOT clobber g
- Host passes `looksam_is_sam_step` (1.0/0.0) + `rho` + `alpha` via FusedScalars.
- ON SAM step (st.looksam_sam == 1):
  1. global ‖g‖ via the deterministic P2.5-style ascending reduce → rho_over_norm.
  2. backup p, perturb p += rho_over_norm·g (per-element, P3-style grid stride).
  3. bar.sync; re-run P1' fwd+bwd at perturbed p into acts (reusable) → write g_sam
     partials, then re-run P2' grad assembly into `sam_grad` (NOT grad).
  4. bar.sync; sam_dir = sam_grad - grad (per element); restore p = sam_backup.
  5. bar.sync.
- ON non-SAM step: sam_dir already holds the cached direction (state carried). No-op.
- P3: apply_optimizer<LookSAM> reads st.sam_dir (already wired in opt_components),
  g_adj=(1-alpha)g+alpha·sam_dir, AdamW. UNCHANGED.

## Re-invocation feasibility (verified)
- dectc_forward_tile / dectc_backward_tile are pure device fns (all state via args:
  weights w=dec_bind(params), acts, scratch, smem). Re-running at perturbed params
  into the same acts/scratch is structurally fine (acts free after P2 grad assembly).
- P2 grad-assembly (dW specs, biases, embed scan, lnvec reduce) writes to a grad ptr.
  For the 2nd pass I point it at `sam_grad`.

## Host plumbing
- dispatch.cpp wgmma_tail_opt_id: add `looksam → 4`.
- dispatch.cpp: thread looksam scalars (rho, alpha already via FusedScalars.alpha,
  sam_step flag) + bind sam workspace; bump TC workspace size for the 2 extra
  total-sized regions.
- _opt_scalars_from: add looksam branch (alpha=group['alpha'], looksam_rho, and the
  SAM-step flag computed from optimizer._global_step % k).
- fused_train_step: forward the looksam extra scalars.
- dispatch.py: add (decoder,looksam) etc to _FUSED_L3_REAL + _L3_WGMMA_CELLS;
  gemm_impl_for_cell already keys off _L3_WGMMA_CELLS.
- train_looksam: call _try_fused_train_step (keep eager sam_step prefix? NO — the L3
  kernel does the SAM 2nd backward in-kernel; on a fused hit skip eager sam_step+step).
  BUT _global_step cadence must still advance so should_sam_step phase matches; the
  host computes the flag from opt._global_step BEFORE the launch and increments after.

## tail_gate reference (CRITICAL)
The gate injects kernel grad into p.grad and runs opt_ref.step() — but LookSAM.step()
blends with sam_dir which is ZERO unless sam_step ran. So the looksam factory/gate
branch MUST run the SAM 2nd backward on the reference: opt_ref.sam_step(m_ref, tx, ty,
crit) at step 1 (a SAM step) BEFORE injecting g and stepping. Then opt_ref.state[p]
['sam_direction'] holds g_sam-g and step() blends faithfully. The (1b) STATE check
compares kernel [m|v|extra] — extra == st.sam_dir; reference's sam_direction maps to
the extra slot. Need a run_cell_gate looksam branch.
